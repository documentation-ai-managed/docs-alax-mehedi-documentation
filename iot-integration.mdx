## IoT Device Integration Overview

PCREPBD's IoT integration capabilities allow seamless connectivity between smart sensors, GPS trackers, and waste management devices with our cloud platform. Our robust API and device management system ensures reliable data collection and real-time monitoring for plastic waste management operations.

Whether you're integrating existing IoT devices or deploying new smart sensors, our platform provides the tools and documentation needed for successful implementation.

<Steps>
  <Step title="Device Registration" icon="plus-circle">

  </Step>
  <Step title="API Authentication" icon="key">

## Data Transmission Protocols

<CodeGroup tabs="MQTT,HTTP,WebSocket">
  ````javascript
// MQTT Protocol Example
const mqtt = require('mqtt');
const client = mqtt.connect('mqtt://api.pcrepbd.com');

client.on('connect', () => {
  client.subscribe('devices/BIN001/data');
  
  setInterval(() => {
    const sensorData = {
      deviceId: 'BIN001',
      fillLevel: Math.random() * 100,
      timestamp: new Date().toISOString()
    };
    client.publish('devices/BIN001/data', JSON.stringify(sensorData));
  }, 300000); // 5 minutes
});
````
  ````javascript
// HTTP REST API Example
const sendSensorData = async (deviceData) => {
  const response = await fetch('/api/devices/data', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
      'Device-ID': deviceData.deviceId
    },
    body: JSON.stringify({
      fillLevel: deviceData.fillLevel,
      weight: deviceData.weight,
      location: deviceData.location,
      timestamp: deviceData.timestamp
    })
  });
  
  return response.json();
};
````
  ````javascript
// WebSocket Real-time Connection
const ws = new WebSocket('wss://api.pcrepbd.com/devices');

ws.onopen = () => {
  ws.send(JSON.stringify({
    type: 'authenticate',
    apiKey: apiKey,
    deviceId: 'BIN001'
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Received:', data);
};

// Send periodic updates
setInterval(() => {
  ws.send(JSON.stringify({
    type: 'sensor_update',
    fillLevel: Math.random() * 100,
    timestamp: new Date().toISOString()
  }));
}, 300000);
````
</CodeGroup>

## Best Practices

<Expandable title="Integration Guidelines" default-open="false">
  Follow these best practices for reliable IoT device integration.

  - Implement exponential backoff for failed transmissions
  - Use data compression for bandwidth-constrained devices
  - Validate data before transmission to reduce errors
  - Monitor device health metrics regularly
  - Keep firmware updated for security and performance
</Expandable>
