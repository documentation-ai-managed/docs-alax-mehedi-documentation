## Getting Started with PCREPBD

PCREPBD is Bangladesh's comprehensive platform for transforming plastic waste management through Extended Producer Responsibility (EPR) compliance and Obligation Based Plastic (OBP) certification. Our IoT-powered smart collection management solutions streamline waste collection processes, ensuring efficient recycling and regulatory compliance.

PCREPBD leverages cutting-edge technology to create a transparent and accountable plastic waste ecosystem that benefits producers, collectors, and the environment.

## API Integration

<Request tabs="cURL,JavaScript" show-lines="true">
  ````bash
curl -X GET "https://api.pcrepbd.com/collections" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
  ````
  ````javascript
const response = await fetch('https://api.pcrepbd.com/collections', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  }
});
const collections = await response.json();
````
